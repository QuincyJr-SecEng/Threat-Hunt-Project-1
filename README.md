<h1>🛡️ Agent-Based Vulnerability Scanning (Windows + Tenable)</h1>

<p>
This project demonstrates hands-on experience deploying and managing <strong>agent-based vulnerability scanning</strong> using <strong>Tenable Nessus Agents</strong> on a Windows virtual machine. The assessment highlights how local agents enable deeper visibility, offline scanning, and reliable vulnerability detection in enterprise environments.
</p>

<h2>🎯 Project Objective</h2>
<p>
Show how agent-based scanning differs from traditional network scans by leveraging locally installed agents to perform authenticated vulnerability assessments, commonly used in modern SOC and Vulnerability Management programs.
</p>

<h2>🧰 Tools & Technologies</h2>
<ul>
  <li>Tenable Vulnerability Management</li>
  <li>Nessus Agents</li>
  <li>Windows Virtual Machine</li>
  <li>PowerShell</li>
  <li>Triggered Agent Scans</li>
  <li>Agent Groups & Scan Policies</li>
</ul>

<h2>⚙️ What This Demonstrates</h2>
<ul>
  <li>Secure provisioning of Windows virtual machines with strong credentials</li>
  <li>Deployment and provisioning of Nessus Agents using PowerShell</li>
  <li>Organizing assets using agent groups for scalable scanning</li>
  <li>Configuring and executing triggered agent-based scans</li>
  <li>Monitoring agent health, linkage, and scan execution</li>
  <li>Analyzing vulnerability findings from local agent scans</li>
</ul>

<h2>📊 Key Outcomes</h2>
<ul>
  <li>Successfully deployed and linked a Nessus Agent to Tenable Cloud</li>
  <li>Executed local, agent-based vulnerability scans using trigger files</li>
  <li>Observed vulnerability population and scan lifecycle behavior</li>
  <li>Reviewed vulnerabilities detected through authenticated local scanning</li>
</ul>

<h2>🧠 SOC & Vulnerability Management Alignment</h2>
<p>
Agent-based scanning is widely used in enterprise environments where systems may be offline, firewalled, or inaccessible to network scanners. This project reflects real-world SOC practices for endpoint visibility, continuous monitoring, and scalable vulnerability management.
</p>

<h2>🔐 Security Best Practices Highlighted</h2>
<ul>
  <li>Avoidance of default or weak credentials</li>
  <li>Use of least-exposed scanning methods</li>
  <li>Verification of agent identity and linkage</li>
  <li>Controlled scan execution via triggers</li>
</ul>

<h2>🧹 Cleanup & Operational Hygiene</h2>
<p>
After validation, all testing artifacts were removed, including scans, agent groups, linked agents, and the virtual machine, reinforcing secure lab practices and cost control.
</p>
